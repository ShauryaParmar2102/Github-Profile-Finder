# 🔎 GitHub Profile Finder

A simple web application that allows users to search for GitHub profiles by username and display public profile information using the GitHub API.

## 🚀 Features

- 🔍 Search for GitHub users by username
- 👤 Display profile picture, name and username
- 📅 Display account creation date
- 📦 Show public repositories
- 👥 Show followers and following
- 🏢 Display company information
- 📍 Display location
- 🔗 Display website
- 𝕏 Display X/Twitter username
- 📝 Display the user's bio
- ⚠️ Show fallback text when profile information is unavailable

## 🛠️ Technologies Used

- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript
- 🔌 GitHub REST API
- ⭐ Font Awesome

## 📸 How It Works

1. Enter a GitHub username into the search bar.
2. Press **Enter**.
3. JavaScript sends a request to the GitHub API.
4. The API returns the user's public profile information.
5. The profile information is displayed dynamically on the page.

## 🔌 API

This project uses the GitHub Users API.
